توثيق الـ API

🔗
RESTful API

يتصل التطبيق بالـ Backend الحالي عبر RESTful API مع مصادقة JWT.

نقاط النهاية الرئيسية

Authentication 
POST   /api/auth/login           # تسجيل الدخول
POST   /api/auth/register        # إنشاء حساب جديد
POST   /api/auth/refresh         # تجديد التوكن
POST   /api/auth/logout          # تسجيل الخروج
POST   /api/auth/forgot-password # استعادة كلمة المرور
Student Endpoints 
GET    /api/student/dashboard    # بيانات لوحة التحكم
GET    /api/student/classes      # قائمة الحلقات
GET    /api/student/attendance   # سجل الحضور
POST   /api/student/recitation   # رفع تسجيل التلاوة
GET    /api/student/homework     # الواجبات المطلوبة
GET    /api/student/exams        # الاختبارات القادمة
GET    /api/student/progress     # تقدم الحفظ
Teacher Endpoints 
GET    /api/teacher/dashboard    # لوحة تحكم المعلم
GET    /api/teacher/students     # قائمة الطلاب
POST   /api/teacher/attendance   # تسجيل الحضور
POST   /api/teacher/evaluation   # تقييم الطالب
POST   /api/teacher/homework     # إضافة واجب
POST   /api/teacher/exam         # إنشاء اختبار
GET    /api/teacher/reports      # التقارير
